# LuxuryHouse Photorealism Reference Library

This folder defines the reference sources for the LuxuryHouse / Blender photorealism workflow.

## Purpose

Use references in four different ways:

1. **Real photography** — visual truth for camera, exposure, materials, reflections, scale and imperfections.
2. **HDRIs** — actual Blender lighting/reflection environments.
3. **PBR materials** — actual Blender surface data.
4. **4K video** — camera movement, framing, walking speed, exposure and transitions.

Do not treat architectural CGI as the physical truth. The target is photographic realism.

## PBR categories to download

Create local asset folders for:

- marble
- travertine
- limestone
- plaster
- concrete
- oak / walnut
- dark metal
- brushed metal
- glass
- stone paving
- pool tile
- leather
- fabric
- carpet
- vegetation

For hero materials prefer complete sets containing albedo/base color, roughness, normal and displacement/height where available.
